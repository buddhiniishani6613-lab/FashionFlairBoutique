# FashionFlair Boutique

## Project Overview
FashionFlair Boutique is a Java-based desktop application developed to manage boutique operations. The system helps manage products, categories, stock details, and daily boutique activities through a simple user interface.

## Technologies Used
- Java
- Java Swing
- NetBeans IDE
- MS Access Database
- UCanAccess JDBC Driver

## Main Features
- Add and manage products
- View product details
- Manage product categories
- Store product information in a database
- Manage stock quantities
- Database connectivity using JDBC

## Product Categories
- Casual Wear
- Formal Wear
- Sportswear
- Footwear
- Accessories

## User Roles
- Sales Assistant
- Store Manager

## Database
The project uses Microsoft Access (`FashionFlairBoutique.accdb`) as its database and UCanAccess for Java database connectivity.

## How to Run
1. Clone or download this repository.
2. Open the project using NetBeans IDE.
3. Make sure the required UCanAccess libraries are added.
4. Check the database connection settings in `DBConnection.java`.
5. Run the main Java class.

## Project Purpose
This project was developed as an Object-Oriented Programming (OOP) project to practise Java programming, database connectivity, and desktop application development.
